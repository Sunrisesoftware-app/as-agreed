# Architecture decision records

One file per decision, rendered from the Atlas model's `decisions[]` for system `as-agreed`. The
model is the source of truth; these files exist so the decisions are readable in the repository
without Atlas. A new decision is added to the model (a PR against the Atlas repository), not here.

The system does not exist in the model yet (BACKLOG ATLAS-1), so there are no records. Until then
the decisions are in [`../DECISIONS.md`](../DECISIONS.md).
